# Export Preview
Display formatted report preview and provide download options for PDF and CSV exports.

Layout Hierarchy:
- Header (Full-width):
  - Page Navigation Bar
- Main Content Area (Positioned below the header):
  - Preview Panel Section
  - Download Actions Section

## Page Navigation Bar
- Back to Reports link
- Page title "Export Preview"
- Current event name display
- Report type indicator

## Preview Panel Section
- Report preview card (styled as document):
  - Report header section:
    - Event name (large, prominent)
    - Event type badge (Wedding/Funeral)
    - Event date
    - Report generation date
    - Report type label (Full Donor Report / Summary Report / Thank You List / Accounting Export)
  - Donation records table/list:
    - Donor names (formatted)
    - Donation amounts (with currency)
    - Timestamps (formatted based on report type)
    - Notes/remarks (if included)
    - Serial numbers or transaction IDs (for accounting export)
  - Summary statistics section:
    - Total donations count
    - Total donation amount (prominent)
    - Average donation amount
    - Date range covered
  - Report footer:
    - Generated by (organizer name/system)
    - Generated on (timestamp)
    - Optional organizer contact information
- Zoom controls (for preview adjustment)
- Page navigation (if multi-page PDF)

## Download Actions Section
- Primary download buttons:
  - Download PDF button (prominent, primary action)
  - Download CSV button (secondary for data export)
  - Download Excel button (if format selected)
- Share options:
  - Copy shareable link button
  - Email report button
  - Print report button
- Additional actions:
  - Regenerate with different settings link
  - Save as template button (for recurring reports)
- Download confirmation message (appears after successful download)
