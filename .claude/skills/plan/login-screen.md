# Login
Allow existing users to securely access their donation management account.

Layout Hierarchy:
- Centered Container:
  - Authentication Form Card

## Authentication Form Card
- Application branding:
  - Logo and application name
  - Tagline "Reliable Donation Tracking for Life's Meaningful Events"
- Welcome message "Welcome Back"
- Login form fields:
  - Email address input field (required, with validation)
  - Password input field (required, with show/hide toggle)
  - Remember me checkbox
  - Forgot password link
- Form actions:
  - Sign In button (primary, prominent)
  - Loading state indicator
- Alternative authentication options:
  - Divider with "Or continue with"
  - Social login buttons (Google, Apple)
- New user prompt:
  - "Don't have an account?" message
  - Sign Up link (prominent)
- Offline capability indicator:
  - Message: "Once logged in, you can work offline"
- Error message display area (for invalid credentials, network errors)
- Footer links:
  - Privacy Policy
  - Terms of Service
  - Contact Support
