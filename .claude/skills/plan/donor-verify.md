# Donor Verification
Provide donors with simple, no-login access to verify their contribution was recorded correctly.

Layout Hierarchy:
- Header (Minimal):
  - Simple Branding Bar
- Main Content Area (Centered, card-style):
  - Verification Display Section

## Simple Branding Bar
- Application name/logo (simple, understated)
- Event context indicator (if applicable)

## Verification Display Section
- Welcoming header message "Thank you for your contribution"
- Event information display:
  - Event name
  - Event type badge (Wedding/Funeral with appropriate styling)
  - Event date
- Donation details card (prominent, well-formatted):
  - Donor name (large, clear)
  - Donation amount (prominent, with currency)
  - Donation date and time
  - Unique verification ID (for records)
  - Confirmation status badge ("Verified" with checkmark icon)
- Privacy notice message (reassuring, concise)
- Optional actions:
  - Download receipt button (generates simple PDF confirmation)
  - Report discrepancy link (if information appears incorrect)
- Footer with:
  - Organizer contact information (optional, if provided)
  - Brief privacy policy link
  - "Powered by Donation Management System" attribution

## Security Notice Section
- Simple message explaining this is a secure, read-only verification
- No personal account required messaging
- Data privacy assurance
