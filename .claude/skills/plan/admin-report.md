# Admin Reports
Comprehensive reporting interface for administrators to generate, view, and export system-wide donation reports and analytics.

Layout Hierarchy:
- Header (Full-width):
  - Top Navigation Bar
- Main Content Area (Positioned below the header):
  - Page Header Section
  - Report Configuration Section
  - Report Preview Section
  - Saved Reports Section

## Top Navigation Bar
- Application logo and name
- Admin role badge
- Main navigation links (Reports active)
- Sync status indicator
- Notifications icon
- User profile menu

## Page Header Section
- Page title "Reports & Analytics"
- Generate New Report button (primary, prominent)
- Saved Reports tab indicator (showing count)
- Report Templates dropdown (predefined report types)

## Report Configuration Section
- Configuration card with sections:

  **Report Scope:**
  - Scope selector:
    - System-Wide (all events)
    - Multiple Events (select specific events)
    - Single Event (dropdown selector)
    - Specific Organizer (dropdown selector)
  - Event type filter (All / Weddings / Funerals)

  **Date Range:**
  - Preset options:
    - Today
    - This Week
    - This Month
    - Last 30 Days
    - Last 90 Days
    - This Year
    - All Time
    - Custom Range (date pickers)

  **Report Type:**
  - Report type selector:
    - Full Donor Report (all donors with amounts and dates)
    - Summary Report (totals and statistics only)
    - Thank You List (donor names formatted for cards/letters)
    - Accounting Export (detailed with timestamps and IDs)
    - Financial Summary (aggregate statistics with charts)
    - Organizer Performance (events and donations by organizer)
    - Comparative Analysis (compare multiple events)

  **Content Options:**
  - Checkboxes for inclusion:
    - Include donor names
    - Include donation amounts
    - Include timestamps
    - Include organizer details
    - Include notes/remarks
    - Include event details header
    - Include summary statistics
    - Include charts/visualizations

  **Grouping & Sorting:**
  - Group by options:
    - None (flat list)
    - By Event
    - By Event Type
    - By Organizer
    - By Date (Daily/Weekly/Monthly)
  - Sort preference:
    - By Date (Recent First / Oldest First)
    - By Amount (Highest First / Lowest First)
    - By Donor Name (A-Z / Z-A)
    - By Event Name (A-Z / Z-A)

  **Export Format:**
  - Format selection:
    - PDF (for printing and sharing)
    - CSV (for spreadsheets)
    - Excel (formatted spreadsheet with charts)
    - JSON (for system integration)

  **Actions:**
  - Generate Report button (prominent, primary)
  - Save as Template button
  - Load Template dropdown
  - Reset Configuration button

## Report Preview Section
- Preview panel (shows after generation):
  - Report header section:
    - Report title (auto-generated or custom)
    - Generation date and time
    - Report scope description
    - Date range covered
    - Generated by (admin name)

  - Report content area:
    - Dynamic content based on report type
    - For donation reports:
      - Donation entries table with selected columns
      - Summary statistics section
      - Charts (if enabled): bar charts, line graphs, pie charts
    - For financial summary:
      - Key metrics cards (total, average, median, highest, lowest)
      - Donation distribution chart
      - Timeline graph
      - Event comparison table
    - For organizer performance:
      - Organizer leaderboard table
      - Events managed count
      - Total donations facilitated
      - Average per event

  - Report footer:
    - Summary totals
    - Page numbers (for multi-page PDFs)
    - System attribution

  - Preview controls:
    - Zoom in/out buttons
    - Page navigation (for multi-page reports)
    - Full screen toggle

## Saved Reports Section
- Saved reports list:
  - Report cards showing:
    - Report name/title
    - Report type badge
    - Date range covered
    - Generation date
    - File format icon
    - File size
    - Generated by (admin/organizer name with avatar)
    - Quick actions:
      - Download button
      - View Preview button
      - Regenerate with same settings button
      - Share button
      - Delete button
  - Filters for saved reports:
    - Report type filter
    - Date generated filter
    - Generated by filter
  - Search saved reports
  - Sort by (Newest / Oldest / Name / Type)
- Pagination for saved reports list
- Empty state (when no saved reports):
  - "No saved reports yet"
  - Generate your first report CTA

## Export Actions Section (appears after generation)
- Primary download button (prominent, format-specific icon)
- Secondary actions:
  - Email report (opens email dialog)
  - Share link (generates shareable URL)
  - Print report (opens print dialog)
  - Schedule recurring report (opens scheduling dialog)
- Download confirmation message
- Auto-save to Saved Reports (with notification)
