# Organizer Reports
Reporting interface for organizers to generate and view reports for their assigned events.

Layout Hierarchy:
- Header (Full-width):
  - Top Navigation Bar
- Main Content Area (Positioned below the header):
  - Page Header Section
  - Report Configuration Section
  - Report Preview Section
  - My Saved Reports Section

## Top Navigation Bar
- Application logo and name
- Organizer role badge
- Main navigation links (Reports active)
- Sync status indicator
- Notifications icon
- User profile menu

## Page Header Section
- Page title "Reports"
- Generate New Report button (primary)
- Report Templates dropdown (Thank You List, Accounting Export, Full Report)

## Report Configuration Section
- Configuration card:

  **Scope:**
  - Event selector:
    - All My Events
    - Single Event (dropdown of my events)
    - Multiple Events (multi-select of my events)
  - Event type filter (All / Weddings / Funerals)

  **Date Range:**
  - Preset options:
    - Today
    - This Week
    - This Month
    - Last 30 Days
    - All Time
    - Custom Range (date pickers)

  **Report Type:**
  - Full Donor Report
  - Summary Report
  - Thank You List
  - Accounting Export

  **Content Options:**
  - Include donor names checkbox
  - Include donation amounts checkbox
  - Include timestamps checkbox
  - Include event details checkbox
  - Include notes/remarks checkbox
  - Include summary statistics checkbox

  **Sorting:**
  - By Date (Recent First / Oldest First)
  - By Amount (Highest / Lowest)
  - By Donor Name (A-Z / Z-A)

  **Format:**
  - PDF
  - CSV
  - Excel

  **Actions:**
  - Generate Report button (primary)
  - Reset button

## Report Preview Section
- Preview panel (after generation):
  - Report header:
    - Report title
    - My name as organizer
    - Event(s) covered
    - Date range
    - Generation timestamp

  - Report content:
    - Donation entries (based on configuration)
    - Summary statistics:
      - Total donations count
      - Total amount
      - Average donation
    - Charts (if applicable)

  - Report footer:
    - Generated by system
    - Page numbers

  - Preview controls:
    - Zoom controls
    - Page navigation (multi-page)

## My Saved Reports Section
- Saved reports list:
  - Report cards showing:
    - Report name
    - Report type badge
    - Event(s) covered
    - Date range
    - Generation date
    - File format icon
    - File size
  - Actions per report:
    - Download
    - View Preview
    - Regenerate
    - Share (if allowed)
    - Delete
- Filter saved reports:
  - Report type
  - Date generated
  - Event
- Search saved reports
- Pagination
- Empty state:
  - "No saved reports"
  - Generate first report CTA

## Export Actions (after generation)
- Download button (primary, with format icon)
- Email report button
- Print report button
- Save to My Reports (auto-saved with notification)
- Download confirmation message
