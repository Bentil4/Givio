# Create Event
Allow organizers to set up a new wedding or funeral event with basic details and context settings.

Layout Hierarchy:
- Header (Full-width):
  - Page Navigation Bar
- Main Content Area (Positioned below the header):
  - Form Container (centered, card-style layout)

## Page Navigation Bar
- Back to Dashboard link
- Page title "Create New Event"
- Sync status indicator

## Event Information Form
- Event name input field (required)
- Event type selection (required):
  - Wedding option (with celebratory icon)
  - Funeral option (with respectful icon)
- Event date picker (required)
- Event location input field (optional)
- Event description text area (optional, for notes or additional context)
- Privacy settings:
  - Allow donor verification toggle
  - Show donation amounts publicly toggle
- Form actions:
  - Create Event button (primary, prominent)
  - Cancel button (secondary)
- Validation messages area
- Offline indicator with message "Event will be created locally and synced when online"
