## Deferred from: code review of story 1-1-secure-login-role-guarded-dashboard-landing (2026-07-26)

- **No `returnUrl` preserved on guard redirect** — a denied/unauthenticated user is always sent to `/login` with no memory of the URL they were trying to reach, so after logging in they land on their default dashboard rather than back where they started. Not required by any Story 1.1 AC. `src/app/auth/guards/role.guard.ts`.
- **Guards attached per top-level route, not via `canActivateChild`** — currently harmless (Angular's `canActivate` on a parent route already protects its children, and each of `admin`/`organizer` has exactly one child today), but nothing structurally forces a future route added directly under `admin`/`organizer` to inherit protection. Worth a checklist reminder as Epic 2+ adds more routes. `src/app/app.routes.ts`.

## Deferred from: GitHub Copilot automated review of PR #79 (2026-09-25)

- **A failed/unresolved `TenantDataService.getMyActiveMembership()` lookup is indistinguishable from "confirmed no Membership"** — `createEvent`'s `.catch(() => null)` (added to fix the offline-first regression) means a Membership-bearing caller who is temporarily offline gets `tenantId: undefined` persisted permanently in the local record and outbox payload; a later sync retry re-sends that same unscoped payload rather than re-resolving the tenant. **Currently unreachable** — no Organizer-tier "Create Event" UI exists anywhere in Epics 6-9 yet (Admin, the only caller today, never has a Membership, so the field is always `undefined` regardless of network state). **Must be fixed before any story builds that UI**: the fix is not a quick patch — it needs a tri-state result (resolved-none / resolved-tenant / unresolved) and the tenant to be re-resolved at or before sync time, not only at initial local creation, which is a genuine (if small) redesign of the outbox/creation flow best done by whichever story actually needs it. `src/app/data/services/event-data.service.ts:117-120`, `src/app/data/services/tenant-data.service.ts`.
